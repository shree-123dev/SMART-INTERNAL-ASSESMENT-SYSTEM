# PROJECT TITLE :  SMART INTERNAL ASSESSMENT & MAINTENANCE SYSTEM (SIAMS)

# PROJECT DESCRIPTION : SIAMS is a web-based application developed to automate the Internal Assessment process in colleges. It helps teachers manage students, attendance, practical marks, assignments, and generate reports automatically. The system also uses QR Code technology for fast attendance marking during practical sessions.

# PROBLEM BEING ADDRESSED : Currently, many colleges calculate internal assessment marks manually using Excel sheets and paper records. This process is time-consuming, error-prone, and difficult to maintain.

# SIAMS solves this problem by
-Automating attendance management
-Calculating internal assessment marks automatically
-Managing practical marks
-Generating reports instantly
-Reducing paperwork
-Improving accuracy and transparency
